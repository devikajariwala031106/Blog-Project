# 🚀 Full-Stack SaaS Management Dashboard

✨ A modern, responsive, and fully dynamic SaaS Management Dashboard built using **Node.js, Express.js, EJS, MongoDB, Mongoose, Bootstrap 5, Passport.js**, and **MVC Architecture**. The project features a clean folder structure, secure authentication, reusable components, and complete CRUD functionality with a premium dashboard UI.

## 🔥 Features

* 🚀 Developed a complete Full-Stack SaaS Management Dashboard using Node.js, Express.js, EJS, MongoDB, Mongoose, and Bootstrap 5.

* 🏗️ Followed a clean and scalable MVC Architecture with separate Config, Controllers, Models, Routes, Middleware, Utilities, Public, and Views folders.

* 🎨 Designed a modern SaaS-inspired UI with responsive layouts, reusable components, premium cards, and interactive dashboard sections.

* 🧩 Converted static pages into dynamic EJS templates using reusable Navbar, Sidebar, Header, Footer, and Layout Partials.

* 🔐 Implemented secure authentication using Passport.js Local Strategy with Login, Logout, Protected Routes, and Session Management.

* 🍪 Used Express Sessions and Cookie Parser for secure user authentication and persistent login sessions.

* 🔒 Secured user passwords using bcrypt hashing.

* 📦 Integrated MongoDB with Mongoose for efficient database management and schema modeling.

* 👥 Built complete User Management with Add, View, Edit, Delete, Search, and Pagination functionality.

* 🗂️ Implemented complete CRUD Operations for Categories and Products.

* 🖼️ Added Product Image Upload functionality.

* 📊 Created a dynamic Dashboard with analytics cards, statistics, recent activity, and quick action sections.

* 👤 Developed Profile Management with profile updates and password change functionality.

* ⚙️ Included Account Settings and Security Settings pages.

* 🛡️ Protected all private routes using custom Authentication Middleware.

* 💬 Implemented Flash Messages for success and error notifications.

* ✅ Added server-side form validation for better data integrity.

* 🌐 Connected all modules through proper Express Routing.

* 📱 Built a fully responsive interface compatible with desktop, tablet, and mobile devices.

* ⚡ Configured dotenv, Nodemon, Static Assets, and Express Middleware for a smooth development workflow.

* 💻 Maintained clean, modular, reusable, and production-ready code throughout the project.

* 🚫 No comments were used in any source code files, following clean production coding practices.
